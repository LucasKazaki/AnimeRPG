# Original dialogue-advance cue v1

Event: `ui.dialogue.advance`. Proposed shared engine/game asset id:
`astral.ui.dialogue.advance.v1`.

This is a newly authored, 110 ms, two-pulse synthetic confirmation sound. It is
intended as a gentle retro-RPG-style dialogue cue, not an exact recreation of a
Genshin or Pokemon asset. No outside recording, extraction or model is used.
Perceptual similarity, listening approval and native playback remain unverified.

Source: `Tools/DialoguePresentation/generate_advance_cue.py` (standard library).
Pin: `expected-manifest.json`. Generate from the repository root:
```
python Tools/DialoguePresentation/generate_advance_cue.py --output ../dialogue-audio-preview
python Tools/DialoguePresentation/generate_advance_cue.py --output ../dialogue-audio-preview --check
```
The output directory must be new and outside the source worktree. The generator
refuses overwrite and any mismatch with the checked-in output pin. The WAV is a
build artifact, not a second tracked derived copy. Ship its generated bytes only
after the audio importer/cooker and native playback path are accepted.

Format: 48 kHz mono signed PCM16; 5,280 frames; 10,604 bytes including WAV header.
SHA-256: `5e59dc027766133335bfcce8f1625d167631f038d2849ed3304a863866340834`.
Integer waveform/envelope arithmetic produces repeatable source bytes; the test
suite checks duration, header, onset/tail, amplitude bounds, hash, corruption,
overwrite, source-directory protection and CRLF pin portability.

The same event/asset should be used by the engine's starter dialogue tutorial and
AnimeRPG, with an optional per-game override. Trigger once per committed visible
line advance. Do not trigger on every letter or on every skipped intermediate
node. Separate UI volume/mute from voices and music; prevent rapid cue stacking
without discarding input. See the engine contract for the pending integration.
No runtime cue registry, WAV decoder, mixer or tutorial hookup is added here.
