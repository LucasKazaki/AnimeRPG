## ART-008 neutral material-gallery decision

Use a small matched gallery before judging authored or generated materials. Each of four source materials is shown on one canonical UV-sphere geometry binding and one canonical hard-edged-cube binding, with decoded dimensions checked against the authored source. Geometry and transforms are intentionally immutable for this calibration fixture: mesh weights, primitive morph targets, and top-level animations are rejected so valid glTF post-accessor or post-node evaluation cannot make one station differ from another. There are no image textures or baked lighting, the camera is fixed at 50 degrees vertical FOV, and white directional key/fill source lights are fixed at 1000/250 lux. The source-only evidence object is closed to the approved `astral_contract` fields. glTF/KHR values are source interchange semantics only. Astral exposure, tonemapping, shader implementation and actual photometric behavior remain engine-owned and unverified.
