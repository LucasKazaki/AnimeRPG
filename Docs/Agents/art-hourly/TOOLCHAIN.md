## ART-008 neutral material-gallery decision

Use a small matched gallery before judging authored or generated materials. Each of four source materials is shown on one canonical UV-sphere binding and one canonical hard-edged-cube binding, with a neutral floor, fixed camera and two directional lights. The independent verifier reconstructs the generator's sphere, cube and plane and requires complete decoded POSITION/NORMAL/TANGENT/TEXCOORD_0/index payload agreement within `1e-6` for floating values. This is stronger than merely checking counts, extents, index lists or face orientation, and rejects geometrically different but superficially plausible fixtures.

The deterministic interchange profile is deliberately narrow. POSITION is FLOAT VEC3, NORMAL FLOAT VEC3, TANGENT FLOAT VEC4, TEXCOORD_0 FLOAT VEC2, and indices UNSIGNED_SHORT SCALAR. Generator-owned object field sets are closed for the root, embedded buffer, referenced bufferViews/accessors, camera/perspective wrapper, punctual-light extension wrapper, meshes/primitives/materials and nodes. Every accessor and bufferView must be used by the calibration geometry. Indexed references must be genuine JSON integers, index accessor bounds must equal the decoded payload, and vertex data must satisfy the glTF component/alignment rules. This prevents invalid interchange metadata from being certified merely because Python can decode the bytes.

Geometry and transforms remain immutable: mesh weights, primitive morph targets and top-level animations are rejected. Normal/tangent pairs must be normalized and orthogonal. Tangent plus reconstructed-bitangent orientation is derived from triangle positions and UVs. The canonical 12x24 sphere measured approximately 0.9914448614 minimum tangent alignment and 0.9588133133 minimum reconstructed-bitangent alignment, so ART-008 uses 0.95 for non-floor geometry and 0.9999 for the planar floor.

Root evidence metadata is closed to the source-only `astral_contract`, nested glTF `extras` are rejected, and deterministic nested objects reject uncontracted optional metadata. There are no image textures or baked lighting. glTF/KHR values remain interchange semantics only. Astral exposure, tonemapping, shader behavior, importer behavior and actual photometric response are engine-owned and unverified.

The fourteenth independent review at `5baec92ac55329f4f462386c6fb113d2eb15b452` produced three P2 repairs: exact integer reference typing, truthful decoded index bounds, and accessor/bufferView alignment checks.
