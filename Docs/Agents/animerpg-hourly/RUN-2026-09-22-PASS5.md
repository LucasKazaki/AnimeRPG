## Implemented increments

- `GAME-022`: Vanguard Heavy resistance and Boss Light resistance, reported explicitly per attack. Standard and previously shipped Bulwark direct-attack damage remain unchanged.
- `GAME-023`: attacks made while the target was already staggered receive a bounded 5/4 damage multiplier; the hit that creates stagger is not retroactively boosted.
- `GAME-024`: technique chains now extend only when the technique type changes among Reaction, Stagger, and Finisher. Repeating the same technique resets the live multiplier to one while preserving the best-chain record.
- `GAME-025`: the new Boss profile starts Solar-weak and changes to Umbral weakness at the exact half-health Pressure threshold; reset returns to the initial phase.
- `GAME-026`: opt-in Endless training records positive damage and techniques without depleting target health. Switching mode starts a clean attempt and preserves profile/assist selection.
- `QOL-006`: selectable Boss training profile with 320 health, 160 posture, phase behavior, and longer practice capacity.
