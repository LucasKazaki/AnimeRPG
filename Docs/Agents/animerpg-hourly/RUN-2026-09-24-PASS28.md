## Implementation

`ShadowbladeLoadoutWorkbench` evaluates candidates on copies of the authoritative loadout, so previews and recommendations never spend parts, equip gear, overwrite presets, or otherwise mutate the live build. Recommendations iterate only the fixed existing module catalogue and use `TryEquipModule()` on copied state as the ownership/slot-compatibility gate. Five explicit build focuses use small deterministic original weights; ties resolve by stable module enum order.

CurrentSlot scope removes any newly activated family bonus from its score so the player can judge the candidate's direct slot contribution. WholeBuild scope scores the complete resulting `ShadowbladeLoadout::Profile()`, preserving the existing Cooling/Rift/Civic family rules. The workbench is owned by `ShadowbladeActions`, so its remembered preset choice and labels live with the existing live protagonist combat/loadout owner rather than a test-only fixture.

Preset recall routes through the existing validated `ApplyPreset()` path. Only success updates the remembered slot. Preset labels require an already-saved slot, trim outer ASCII spaces, preserve internal spaces, reject empty/over-24-byte/control-character values atomically, and clear without changing the saved preset or equipped build.
