## Implementation

`ShadowbladeLoadout` now tracks bounded weapon/module tune ranks, spends deterministic tuning-part costs, reports exact remaining rank-cap budgets, produces a stable cheapest-next-upgrade recommendation for equipped gear, returns half of invested module tuning parts on salvage in addition to base salvage value, and supports explicit module protection against accidental salvage. Invalid IDs, insufficient parts, level gates, max ranks, and protection failures are non-mutating.

Tune bonuses feed through the existing `ShadowbladeLoadout::Profile()` path. Edge, Ward, Flow, and Insight ranks increase Attack, Guard, Resource Recovery, and Mobility respectively; weapon calibration raises Attack with a smaller Guard increase. The already-live pass-17 `ShadowbladeActions::CurrentLoadoutTuning()` therefore consumes these effects without a parallel action/combat system.
