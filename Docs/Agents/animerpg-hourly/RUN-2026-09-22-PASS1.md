## Scope delivered on the branch

Six bounded production-domain increments were implemented:

- `GAME-001`: normalized direction-aware dash API with safe forward fallback for neutral/nonfinite input.
- `GAME-006`: combo tracking for successful light/heavy attacks, including timeout and best-combo state.
- `GAME-003`: bounded enemy posture, stagger window, posture recovery, and one-shot stagger consumption.
- `GAME-004`: Fatal Strike follow-up that earns a reduced resource cost from an active stagger opening and consumes the opening only after all rejection checks pass.
