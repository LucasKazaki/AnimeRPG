## Implemented game changes

- **GAME-102** adds an original three-stage Mana Reactor expedition, gated by the existing completed Rift Investigation, with authoritative stage/hazard state and bounded 0..100 progress percentage.
- **GAME-103** adds stage-specific heat/stability pressure plus Stabilize, Balance, and Overdrive controls. Heat/stability are clamped to 0..100, invalid controls are non-mutating, and thermal/stability failure cannot advance a stage.
- **GAME-104** adds one optional thermal/stability challenge target per stage. Optional targets affect result quality but never block main progression.
- **GAME-105** adds a consequence-free Calibration mode using the same reactor control contract while refusing first-clear progression rewards.
- **GAME-106** adds deterministic Bronze/Silver/Gold completion, bounded score, best Expedition score retention, replay, and a progression-owned one-time first-clear package of 350 XP, 35 mastery points, and 50 enhancement materials.
- **QOL-022** adds explicit `RetryCurrentStage()` versus `StartOver()`. Current-stage retry preserves earlier cleared stages and optional targets; Start Over resets run-local progress while retaining selected mode.
