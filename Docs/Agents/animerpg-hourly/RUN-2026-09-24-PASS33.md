## Research and implementation

This bounded packet maps five distinct comparator mechanics plus one new community QoL request into the existing persistent single-protagonist Shadowblade combat path:

- `GAME-162`: equipped core talents are now authoritative live combat specializations; upgraded-but-unequipped talents do nothing.
- `GAME-163`: equipped ShadowStep plus Dash mastery gives a bounded successful-dash resource refund.
- `GAME-164`: equipped EclipseEdge plus FatalStrike mastery gives a bounded refund only on the existing earned perfect-defense counter follow-up.
- `GAME-165`: equipped BreakerFocus plus FatalStrike mastery gives a bounded refund only on the existing stagger follow-up.
- `GAME-166`: existing Dash/FatalStrike/Defense practice ranks now affect the corresponding live action resource economy; precise Defense mastery restores bounded resource only on PerfectGuard/PerfectDodge.
- `QOL-034`: a deterministic read-only build briefing reports exact talent tiers, skill ranks, refunds/restores and effective costs.
