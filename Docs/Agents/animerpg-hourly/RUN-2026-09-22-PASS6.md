## Delivered candidate

This packet adds six bounded game-domain increments:

- GAME-027: selectable tactical focus for Balanced, Reaction, Stagger, or Finisher execution.
- GAME-028: deterministic side goals for flawless play, technique variety, speed, and tactical-focus execution.
- GAME-029: composite challenge scoring using existing combat score plus tactical and side-goal points.
- GAME-030: Standard, Expert, and Apex challenge/rank thresholds. Apex requires three side goals for Bronze, four for Silver, and four plus Gold time for Gold.
- GAME-031: one-time first-clear resource reward per challenge difficulty, applied through the existing Shadowblade cap and preserved across retries.
- QOL-007: optional TechniqueFirst scoring that reduces raw base-score weight and increases technique/side-goal value instead of increasing enemy HP.

Challenge behavior is opt-in. An unconfigured `LandmarkEncounter` keeps the existing grade/reward behavior.

## Verification and review repairs

Initial focused source checks used the intended `EncounterChallenge.h` rules and challenge cases:

- GCC C++17 with `-Wall -Wextra -Werror -pedantic`: PASS.
- Clang C++17 with AddressSanitizer + UndefinedBehaviorSanitizer and leak detection: initial run exposed signed overflow while summing three `INT_MAX` tactical counters in Balanced focus. The implementation was corrected to widen before addition and use saturating 64-bit multiplication. The same sanitizer test then PASSed.

Independent Codex review of an earlier head found two material issues:

1. P1: the focused pass-6 regression executable was not registered with CTest, so green hosted CTest would not exercise those cases. Fixed without touching CMake or engine PR #13 by moving the challenge regressions into the already-registered `LandmarkInteractionTests` target and deleting the unregistered duplicate file.
2. P2: Apex lower-rank thresholds were not stricter than Expert. Fixed with explicit Apex boundaries and registered coverage for 2 goals = None, 3 = Bronze, 4 = Silver unless Gold time, and Gold only with all four goals plus Gold time.

Registered coverage now exercises challenge-disabled behavior, tactical focus and side goals, Standard/Expert/Apex ranks, first-clear idempotency, TechniqueFirst weighting, negative-input clamping, and `int64_t` saturation.

Exact final-head hosted Windows Debug/Release deterministic tests, release-manifest integrity, and a fresh independent Codex review remain merge gates until their receipts exist. Native interactive gameplay was not run and is not claimed.
