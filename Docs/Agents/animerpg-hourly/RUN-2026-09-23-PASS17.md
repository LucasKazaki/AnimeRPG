## Independent-review findings and repairs

Fresh Codex review on initial candidate `f8c5daf26504930b890279a83867fc79a7ab02aa` found two material P2 issues.

1. `LandmarkEncounter::Retry` rebuilt `ShadowbladeActions` from scratch, which would erase acquired/equipped items and saved presets. The repair snapshots the persistent `ShadowbladeLoadout`, executes the existing transient reset, restores the loadout, and preserves the existing defense timing preset. A production-path regression now covers this retry flow.
2. The original legal-catalogue build never exceeded most action-tuning clamp thresholds, so loose upper-bound assertions did not prove the clamps existed. The repair exposes the pure profile-to-action transform, changes its clamp arithmetic to overflow-safe `std::clamp`, and directly exercises `INT_MAX` and `INT_MIN` profiles against exact cap/baseline outputs. These repairs do not count as extra game features.

The initial candidate's Windows Debug/Release and release-manifest workflows passed, but those receipts became stale after the review repairs. Exact-final-head hosted verification and a fresh exact-head independent review are required before merge.
