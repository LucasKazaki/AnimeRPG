## Material deliverable

The v2 generator creates four original 512 x 512 repeatable material families: limestone, concrete, brushed steel and asphalt. Each has base color, tangent-space normal, ORM and height maps, for 16 PNGs total plus a manifest. The maps are standalone rather than atlas tiles, eliminating the first pack's atlas-gutter/repeat problem.

Generator version `astral-materials-v2-2` samples 512 unique texels over one complete periodic `[0,1)` domain instead of duplicating the first sample at texel 511. Wrapped normal derivatives use modulo 512 across the repeat boundary.

`Content/Starter/MaterialsV2/expected-manifest.json` pins the exact generated file sizes and SHA-256 hashes. Generated binaries stay outside Git in this slice because the engine has no importer/render path yet. No third-party texture pixels or generated-service outputs are present. These are procedural calibration/default sources, not artist-finished hero materials.

## Independent review findings and repairs

Codex review of initial head `e1c4d0fecec704aa342c06e0dbcfaca34f3f979a` completed on 2026-09-22 and found four issues:

1. **Authorization:** the task packet could not self-authorize a new art worker while repository controls still paused production art. Lucas's explicit operator instruction is now recorded in the two controlling agent/operator documents as a narrow parallel art authorization.
2. **PNG inflation:** the validator could inflate an 8 MiB compressed stream before validating dimensions/decoded size. It now bounds dimensions at IHDR and uses `decompressobj().decompress(..., expected + 1)` so decoded allocation is capped before semantic checks.
3. **Metallic semantics:** validation sampled only every 32nd row/pixel. It now inspects the blue metallic channel of every ORM texel.
4. **Periodic endpoints:** the generator sampled `x/(SIZE-1)` and duplicated periodic endpoints. It now samples `x/SIZE` and `y/SIZE` and wraps gradient neighbors modulo `SIZE`.

The repair also validates every normal Z value, verifies every height texel is replicated grayscale, and rejects anomalous repeat-boundary discontinuities relative to ordinary adjacent steps.
