## Findings fixed in this candidate

1. `Tests/MathTests.cpp` and much of `Tests/SceneTests.cpp` use `assert`; the latter
   calls `LoadFromFile` inside assert. Release NDEBUG disabled checks and calls.
   All 14 CMake test targets now use `astral_add_test`, which undefines NDEBUG for
   tests only and compiles `Tests/AssertionsEnabled.cpp` as a guard. AstralGame's
   Release optimization, NDEBUG, and runtime-library settings are unchanged.
2. Six native RuntimeSmoke tests could overlap under parallel CTest while sharing
   foreground-window and keyboard state. They now use RUN_SERIAL and 180-second
   CTest limits. Domain tests have 60-second limits. Separate CTest invocations
   still need exclusive desktop ownership; these settings are not an OS-wide lock.
3. Multiple native commands in the old PowerShell verifier step could hide an
   earlier failure. Explicit exit checks now stop on each failure, including
   git checks. CTest also fails when no tests are discovered. CI uses an external
   build root and watches the new CMake helper directory.
4. Current direction was isolated on a side branch, while main linked agents to
   historical recovery/backlog instructions. The branch retains director history,
   exposes the current scope, and distinguishes local claims from observed evidence.
